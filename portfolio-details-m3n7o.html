M3N7O Microbots - AI Presentation Generator

  • Category: Major Project, AI/ML
  • Project date: September 2025
  • Project URL: github.com/Pratik-Karale/M3N7O_microbots
  • Technologies/Tools:

An AI-powered presentation generator that creates professional PowerPoint slides from uploaded documents and images using the Gemini 1.5 Flash API. Features a React 18 frontend with Vite, Redux Toolkit, and TailwindCSS, plus Framer Motion animations. The Express backend handles PDF, DOCX, and image processing with custom light/dark slide templates and real-time generation. Built with D3.js and Recharts for data visualization.
