Battleship Multiplayer Game

  • Category: Game, Major Project
  • Project date: November 2025
  • Project URL: github.com/Pratik-Karale/battleship
  • Technologies/Tools:

A full-featured multiplayer Battleship strategy game with AI opponents, real-time online play via Socket.IO, and complete TDD test coverage (51+ commits). Features drag-and-drop ship placement, strategic AI, JWT authentication, and ngrok tunneling for public multiplayer access. Built with modular ES6 architecture using Webpack and Babel.
